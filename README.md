# Servicio Social
## Desarrollo de herramientas para el análisis de datos epidemiológicos 
### Agosto 2024 a Septiembre 2025, ENES Juriquilla, UNAM

Hola, soy Hannia Dominguez, en este repositorio te daré a conocer cómo realicé mi servicio social 😁. 

El objetivo principal fue crear una herramienta digital interactiva para visualizar y analizar modelos epidemiológicos utilizando datos reales. Combinando fundamentos teóricos con análisis computacional en Python, para facilitar la comprensión del comportamiento de enfermedades infecciosas.
En este  repositorio podrás encontrar el desarrollo de un entorno que integra **modelos matemáticos epidemiológicos** (como SIR, Gompertz y Janoschek) con **análisis de datos reales**, permitiendo la estimación de parámetros, simulación de curvas y comparación con datos empíricos.

## Características principales
- Implementación de modelos epidemiológicos clásicos y heurísticos.  
- Estimación automática de parámetros a partir de datos reales.  
- Visualización interactiva de resultados.  
- Interfaz intuitiva desarrollada en Panel.  
- Integración con librerías de análisis y visualización de datos (NumPy, Matplotlib, SciPy).

## Tecnologías utilizadas
- **Lenguaje:** Python 3. 12.7 
- **Librerías:** NumPy, Matplotlib, SciPy, Panel, Pandas, io, Plotly, datetime
- **Entorno:** Visual Studio Code  

## Estructura del repositorio
La carpeta titulada **SS_Git** contiene todos los códigos implementados, dentro se encuentran otras carpetas para su mejor organización. La carpeta titulada **FinalVersion** contiene la implementación final y funcional del dashboard.
